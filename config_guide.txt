================================================================
  GameEngine — Developer Setup Guide
================================================================
Platform : Windows 10/11
Compiler : MSVC (Visual Studio 2022 Build Tools)
Build     : CMake >= 3.20
Language  : C++17

----------------------------------------------------------------
STEP 1 — Install Visual Studio 2022 Build Tools
----------------------------------------------------------------
Required for the MSVC compiler (cl.exe) and Windows SDK.

  winget install Microsoft.VisualStudio.2022.BuildTools --accept-package-agreements --accept-source-agreements

After install, open "Visual Studio Installer" and make sure the
workload "Desktop development with C++" is checked, then install.

----------------------------------------------------------------
STEP 2 — Install CMake (>= 3.20)
----------------------------------------------------------------
  winget install Kitware.CMake --accept-package-agreements --accept-source-agreements

Verify:
  cmake --version

----------------------------------------------------------------
STEP 3 — Install Vulkan SDK
----------------------------------------------------------------
Download and install the latest Vulkan SDK from:
  https://vulkan.lunarg.com/sdk/home#windows

During install, keep the default options (includes glslc compiler
and validation layers which are required).

Verify:
  vulkaninfo --summary

----------------------------------------------------------------
STEP 4 — Install GLFW 3.4 (prebuilt Windows binaries)
----------------------------------------------------------------
Download "Windows pre-compiled binaries" (64-bit) from:
  https://www.glfw.org/download.html

Extract and place the folder at exactly:
  C:\Tool\glfw-3.4.bin.WIN64\

Expected structure inside that folder:
  include\GLFW\glfw3.h
  lib-vc2022\glfw3.lib

Note: The path is hardcoded in CMakeLists.txt. If you place it
elsewhere, update the GLFW_DIR variable in CMakeLists.txt.

----------------------------------------------------------------
STEP 5 — Install Python 3.13
----------------------------------------------------------------
Used by the build system to sync res/ to the build output folder
(only copies changed files for performance).

  winget install Python.Python.3.13 --accept-package-agreements --accept-source-agreements

Verify (open a new terminal after install):
  python --version

Note: If Python is not on your PATH, CMake will still find it at
the default install location automatically.

----------------------------------------------------------------
STEP 6 — Clone the repository
----------------------------------------------------------------
  git clone <repository-url>
  cd GameEngine

Vendor libraries (tinygltf, stb_image, nlohmann/json) are already
included in the vendor/ directory — no extra download needed.

----------------------------------------------------------------
STEP 7 — Build the project
----------------------------------------------------------------
  cmake -S . -B build -G "Visual Studio 17 2022" -A x64
  cmake --build build --config Debug

Or for Release:
  cmake --build build --config Release

The executable will be at:
  build\Debug\GameEngine.exe
  build\Release\GameEngine.exe

The res/ folder is automatically synced to the build output folder
after each build via scripts/copy_res.py.

----------------------------------------------------------------
STEP 8 — Compile shaders (if modified)
----------------------------------------------------------------
GLSL shaders live in res/shader/. Compiled .spv files are already
checked in, but if you modify a shader recompile with glslc
(comes with the Vulkan SDK):

  glslc res/shader/<folder>/vert_shader.vert -o res/shader/<folder>/vert_shader.vert.spv
  glslc res/shader/<folder>/fragment_shader.frag -o res/shader/<folder>/fragment_shader.frag.spv
