===== RULES WE AGREED =====
- Engine API + stored text = UTF-8 std::string. Vulkan side (Label_2D_Description::text, Font_2D::set_text,
  layout) = std::u32string only. Convert once at the boundary with Helper::utf8_to_u32_nfc. No std::string
  overloads on the Vulkan side, so a forgotten conversion is a compile error.
- Every index that crosses the boundary (caret, anchor, max length, char x) is a CODE POINT index, never a byte.
- Edit box text model = std::u32string kept in NFC. Backspace removes exactly one code point
  (Telex tools like OpenKey / EVKey send Backspace + the new letter).
